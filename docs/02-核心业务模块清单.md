# 02 · 核心业务模块清单

## 一、五字 × PMP × 系统如何固化（设计骨架）

| 动作 | 对应 PMP 知识领域 | 系统如何「固化」 |
|------|----------------|---------------------|
| **拆** | 范围管理（WBS）、相关方（RACI）、整合（章程→可交付物） | 任务必须带「责任人+交付物+截止时间+验收标准」才能创建；WBS 逐级分解；RACI 强制明确「谁执行/谁拍板/谁知会」 |
| **控** | 风险管理、变更控制、质量、进度/成本监控（EVM） | 风险台账带等级/影响/应对/责任人/关闭时间；变更走闭环；CPI/SPI 阈值自动红黄绿 |
| **推** | 相关方、沟通、整合（决策） | 问题以「选择题」登记（选项+影响+决策人+截止）；超时自动升级；决策全程留痕 |
| **追** | 监控过程组、质量验收、沟通（行动项） | 逾期自动提醒；任务「完成」须上传交付物+确认关闭；行动项追踪到闭环 |
| **回** | 整合（收尾）、质量（持续改进）、组织过程资产 | 强制结构化复盘；结论沉淀为模板/清单/预警项，喂给下一个项目 |

## 二、各动作的具体业务规则

### ① 拆 — 固化范围与责任
- 禁止「无交付物的任务」：创建任务必须选交付物类型。
- 「完成系统上线」不是一个任务，强制展开为：需求确认→原型评审→开发排期→接口联调→测试验证→用户培训→上线准备→验收确认→问题闭环，缺环不允许「规划完成」。
- 责任拆到人：不写「业务部负责确认」，而是「谁确认需求/流程/数据/验收标准/最终拍板」，对应 RACI。

### ② 控 — 固化风险前置
- 「每次风险都被轻轻放过去」是项目失控的根因。每个风险须有**应对措施+责任人+关闭时间**，否则永远「未处理」并报警。
- 客户说「后面可能加需求」→ 当场登记为**变更候选项**，而非「到时候再看」。
- CPI/SPI 低于阈值（如 0.9）自动红灯，强制 PM 填纠偏方案。

### ③ 推 — 固化决策落地
- 「问题」与「待决策项」分开管理。待决策项须填：**2+ 方案 + 各对进度/成本/范围的影响 + 唯一决策人 + 截止时间**。
- 到点未决策，自动 @ 决策人并抄送上级（升级）。

### ④ 追 — 固化闭环（不是提醒）
- 区分**「状态」和「闭环」**：「差不多了」不能标完成——须交付物上传 + 责任人「确认关闭」。
- 文章的追问清单（哪个版本？谁拍板？有无纪要？影响哪个节点？）系统化成**任务关闭前强制检查项**。
- 逾期、阻塞、无更新超 N 天，系统主动推送，PM 不用「天天催」。

### ⑤ 回 — 固化经验回收
- 项目收尾强制触发**结构化复盘**：逐项过目标达成/范围失控/进度偏差/成本/质量集中点/客户满意度。
- 复盘结论不允许空话，须产出**至少 1 条可复用资产**（模板/清单/规则/预警项），归入经验库，下个类似项目立项自动推荐。

## 三、五字在全生命周期的落点

| 过程组 | 主导动作 | 系统强制行为 |
|-------|---------|------------|
| 启动 | 拆 | 立项即出章程 + 初步 WBS + 相关方清单 |
| 规划 | 拆 + 控 | 拆到工作包 + 建基线 + 风险台账 |
| 执行 | 推 + 追 | 决策卡驱动 + 闭环确认 |
| 监控 | 控 + 追 | EVM 预警 + 异常自动追踪 |
| 收尾 | 回 | 结构化复盘 + 经验入库 |

> 「追」和「控」贯穿执行全程，不只在收尾。

## 四、精炼后模块地图（✅ 市场标配 / 🚀 我们的刃）

| 五字 | 模块 | 关键能力 | 来源 |
|------|------|---------|------|
| 拆 | WBS 与责任分解 | 强制带交付物/责任人/截止/验收；自动拆解建议 | ✅ + 🚀(AI) |
| 拆 | 组合与立项 | 战略评分、容量、stage-gate | ✅ |
| 控 | 基线与变更控制 | 基线锁定、变更闭环、影响分析 | ✅ |
| 控 | EVM 健康度 | CPI/SPI 自动反推、红黄绿预警 | ✅ + 🚀(无痛化) |
| 控 | 风险与问题 | 领先指标、触发式剧本、pre-mortem 闸 | 🚀 |
| 推 | 决策管理 | 决策卡(选项+影响+截止)、决策债看板、自动升级 | 🚀 |
| 推 | 沟通与相关方 | 相关方矩阵、信息辐射源、通知规则 | ✅ |
| 追 | 任务与闭环执行 | 看板/甘特、依赖、逾期自动追、闭环确认 | ✅ + 🚀(强制闭环) |
| 追 | 自动化引擎 | 规则触发、状态流转、提醒升级 | ✅ |
| 回 | 复盘与经验库 | 数据驱动复盘、自动生成模板/清单/预警项 | 🚀 |
| 全 | 项目健康分 | 单一综合分（融合 EVM+风险+决策债） | 🚀 |
| 全 | AI 副驾 | 拆控推追回全流程 AI 辅助 | 🚀 |
