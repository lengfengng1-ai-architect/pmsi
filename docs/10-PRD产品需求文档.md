## 1. 概述

### 1.1 背景
市面项目管理工具多停留在「任务跟踪 + 看板」，PMP 高价值能力（范围分解、成本预算、风险与变更控制、相关方对齐、价值度量）普遍缺失或难用；决策埋在群聊里、复盘流于形式、项目健康靠感觉。

### 1.2 问题陈述
项目「做了不少、价值看不到」；范围蔓延无控制；风险事后救火；经验不沉淀；项目经理沦为「传声筒 + 催办员」。

### 1.3 产品定位
**让战略落地到交付、可度量、可复盘的项目经营系统**——把顶级 PM 的做事方式（拆、控、推、追、回）用 PMP 专业方法固化成不依赖个人能力的组织能力。

### 1.4 价值主张
- 给项目经理：从「天天催天天问」解放，专注判断与推动决策。
- 给管理层：一个数（健康分）说清项目行不行。
- 给组织：把一次项目的经验变成下一次项目的能力。

## 2. 目标用户与典型场景

| 角色 | 核心场景 |
|------|---------|
| 发起人/高管 | 看组合健康度、批章程与基线变更、go/no-go |
| PMO | 配模板/权重/SLA、组合治理、度量 |
| 项目经理 | 拆 WBS、控风险变更、推决策、追闭环、带复盘 |
| 团队成员 | 执行任务、报工时、上传交付物、确认闭环 |

> 操作角色全集（含系统管理员 Admin、决策人、CCB、相关方）见 [docs/11](11-权责与访问范围设计.md)。

## 3. 范围

### 3.1 MVP（P0）In Scope
立项/章程、WBS 与责任分解、任务与闭环执行、基线与变更控制(轻)、风险与问题、**决策管理+自动升级**、自动化(核心规则)、结构化复盘、健康分(轻)、**里程碑**。

### 3.2 Out of Scope（MVP 不做）
组合层、完整 EVM(CPI/EAC)、决策债可视化、经验库跨项目复用、AI 副驾、相关方矩阵、自定义自动化、工时/资源、完整 CCB。（理由见 docs/08）

## 4. 功能需求详述

> 编号规则 `FR-<模块>-NN`。**验收 AC 的权威目录与 P0/P1 归属见 [docs/06](06-验收标准清单.md)**；本文仅做需求描述，AC 以 06 为准（`[补]`=反检验/审查补丁）。

### 4.1 立项与项目章程（P0）
**FR-PRJ-01** 创建项目并生成章程。**FR-PRJ-02 [新]** 状态门：无基线不得进入"执行中"（AC-BASE-01）。**FR-PRJ-03 [新]** 最大执行期/无活动 N 月进"挂起评审"（防永不结项，P1）。

### 4.2 WBS 与责任分解（P0）
**FR-WBS-01** 任务创建强制带 交付物+责任人+截止+验收标准。**FR-WBS-02 [新]** 基线后 WBS 增删/交付物变更/工期超容差自动生成变更申请；冻结度按系统 diff 算（防范围漂移合法化）。**FR-WBS-03 [新]** 任务撤裁计入 S7（防拆分稀释逾期率，P1）。

### 4.3 任务与闭环执行（P0）
**FR-TASK-01** 区分"状态/闭环"，须交付物 + 责任人确认关闭。**FR-TASK-02 [补·新]** 确认人须责任人、禁自审（单人走 AC-SOLO-01）；交付物过 AC-X01a 质量门。**FR-TASK-03** 逾期/阻塞自动推送。状态机见 docs/07 图5。

### 4.4 基线与变更控制·轻（P0）
**FR-BASE-01 [新]** 强制基线：执行前必须建基线（AC-PRJ-02 状态门），缺失则范围/进度否决"未启用(无基线)"且不得绿。**FR-BASE-02 [新]** 重建基线历史方差不归零、需发起人审批（防洗白，P1）。**FR-BASE-03** 触及范围/进度/成本走变更申请。**FR-BASE-04** MVP 变更(轻)发起人确认。状态机见 docs/07 图7。

### 4.5 风险与问题（P0）
**FR-RISK-01** 风险须应对+责任人+关闭时间，否则报警。**FR-RISK-02 [新]** 应对策略枚举 {规避 Avoid, 转移 Transfer, 减轻 Mitigate, 接受 Accept}，按策略联动。**FR-RISK-03 [新]** 高危风险关闭须发起人/PMO 确认（禁自开自关）；风险→问题重分类保留记录双计 S4。**FR-RISK-04** "可能加需求"当场登记变更候选项。状态机见 docs/07 图6。
> 注：CPI/SPI 属 EVM（P1），不在此模块 AC（审查修正）。

### 4.6 决策管理（P0 · 核心护城河）
**FR-DEC-01..06** 决策卡创建/生命周期/自动升级/留痕/联动/RACI-SLA（详见 [docs/05](05-决策管理.md)）。**本模块 P0 AC 子集见 docs/06 §11**（非全部 25 条都进 MVP）。状态机见 docs/07 图4（含 `已执行→待决策` 回退、升级中 T2 超时代决）。

### 4.7 自动化·核心规则（P0）
**FR-AUTO-01** 硬编码核心规则：决策到期升级、任务逾期提醒、风险无应对报警、健康阈值触发动作。MVP 不做自定义引擎（P1）。

### 4.8 结构化复盘（P0）
**FR-RET-01** 收尾强制结构化复盘（六维）。**FR-RET-02 [新]** 产出 ≥1 结构化资产（模板可导入/规则可挂预警/清单可 attach），PMO 抽审入库，拒绝即不予结项。**FR-RET-03 [新]** MVP 资产落单项目资产对象（跨项目复用属 P1 FR-KB-01）。状态机见 docs/07 图8。

### 4.9 健康分（P0 轻版 / P1 完整）
**FR-HEALTH-01** MVP 轻版：4 信号（进度完成偏差/逾期任务/阻塞逾期决策/高危未关风险）+ 否决（按 AC-HS-06b 标注启用）→ 粗粒度红黄绿；缺数据/无基线显"灰"不得绿（AC-HS-04a）。标量须证据化（AC-X02）。
**FR-HEALTH-02 [新] · 状态转换动作（P0）**：绿→黄 24h 纠偏（须可追踪行动项 AC-HS-18a）、黄→红 48h 恢复计划（AC-HS-19）、红持续上抛组合层（AC-HS-20）；**转好须迟滞 ≥2 周期、红→绿禁止**（AC-HS-07b）；全程审计日志（AC-HS-21）。

### 4.10 里程碑（P0 · 新增）
**FR-MS-01 [新]** 里程碑为一等对象：go/no-go、决策阻塞、否决均挂它；须有日期/责任人/验收标准。**FR-MS-02 [新]** 里程碑滑移计入健康分；阻塞它的决策/风险自动关联。

### 4.11 P1 功能（概要）
| 编号 | 模块 | 要点 | 优先级 |
|------|------|------|:---:|
| FR-EVM-01 | EVM 完整 | **CPI/SPI + EAC/VAC/TCPI**；须工时+预算+基线三输入（非"从工时反推"） | P1 |
| FR-HEALTH-03 | 健康分完整 | 8 维+一票否决+趋势，详见 docs/04 | P1 |
| FR-DEBT-01 | 决策债可视化 | 债值/最老/阻塞链 | P1 |
| FR-KB-01 | 经验库跨项目复用 | 立项自动推荐同类经验 | P1 |
| FR-RES-01 | 工时/资源 | 工时录入、资源过载检测 | P1 |
| FR-CCB-01 | 变更控制完整 | CCB 审批、基线重建 | P1 |
| FR-AUTO-02 | 自定义自动化 | 规则引擎 | P1 |

### 4.12 P2 功能（概要）
FR-PORT-01 组合管理(战略评分/容量/stage-gate)、FR-STAKE-01 相关方矩阵、FR-DEP-01 依赖增强、FR-RPT-01 报表/仪表盘。**Program（项目集）层**纳入三层架构（Portfolio/Program/Project/Delivery）。

### 4.13 P3 功能（概要）
FR-AI-01 AI 副驾（可行性/数据准备/幻觉防护见 docs/13）、FR-TRAIN-01 辅助轮模式、FR-ADV-01 pre-mortem/风险剧本、FR-BENCH-01 跨组织对标。

## 5. 业务规则总览（固化清单）

| 规则 | 出处 |
|------|------|
| 任务须带交付物/责任人/截止/验收方可创建 | 拆 |
| 基线强制（执行前必建）| 控 |
| 风险须有应对/责任人/关闭 + 四策略枚举 | 控 |
| 决策须 ≥2 互斥选项 + 唯一决策人 + 合理截止 | 推 |
| 决策超时自动升级 + 升级中硬超时代决 | 推 |
| 任务闭环须交付物 + 独立确认（禁自审）| 追 |
| 复盘须产出 ≥1 结构化资产 + PMO 抽审方可结项 | 回 |
| 凡提交/确认/解除类动作须产出可追踪对象，禁纯文本（AC-X01） | 横切 |
| 进入健康分/否决/决策债的标量须证据化（AC-X02） | 横切 |
| 状态变更全程留痕，不可删（可追加更正） | 治理 |

## 6. 非功能需求（业务级）

| 类别 | 要求 |
|------|------|
| 治理 | PMO 可配置权重/阈值/SLA；权重变更仅对未来生效、项目级设定后不可中途改 |
| 数据完整性 | 关键状态变更留痕、可回溯任意时刻快照；记录不可物理删除 |
| 权限 | 基于角色与 RACI（docs/11）；决策人/确认人唯一可执行性校验 |
| 合规/隐私 | 审计日志 append-only；等保/GDPR/个保法主体权利；敏感字段分级；详见 docs/13 |
| 自动化可靠性 | 关键动作系统自动执行，降人工依赖；归档项目冻结自动化 |
| 可裁剪 | 支持预测/适应/混合模式，按项目类型开关流程 |
| 可用性/性能/集成/移动端 | 见 docs/13 现实工程设计 |

## 7. 成功指标与北极星

### 7.1 MVP 北极星（加正向门槛，防空项目空洞满足）
1. 无交付物的任务关不掉；
2. 超 SLA 的决策系统必升级；
3. 无应对的高危风险必报警；
4. 收尾产出可复用经验。
> 须同时满足**正向门槛**：≥N 个任务、≥1 个已关闭决策、≥1 条已闭环风险、≥1 条被引用/入库资产，才进入北极星统计。

### 7.2 量化指标
范围非受控变更率↓、决策平均关闭时长↓、决策债总值↓、复盘资产复用率↑、健康分预测准确度↑、PM 人均管理项目数↑。

## 11. 附录

### 11.1 术语表
| 术语 | 释义 |
|------|------|
| WBS | 工作分解结构 |
| EV / PV / AC / BAC | 挣值(预算×完成度) / 计划价值(基线进度) / 实际成本 / 完工预算 |
| CPI / SPI | 成本绩效=EV/AC / 进度绩效=EV/PV |
| EAC / VAC / TCPI | 完工估算=BAC/CPI / 完工偏差=BAC−EAC / 完工尚需绩效指数 |
| RACI | **R**=负责执行 · **A**=问责(最终担责,唯一) · **C**=征询 · **I**=知会 |
| CCB / 治理委员会 | 变更控制委员会；"治理委员会 = CCB（或其授权上级）"，全文统一 |
| stage-gate | 阶段门治理 |
| 决策债 | 逾期决策按「天数×影响」累计的等待成本 |
| 拆控推追回 | 顶级 PM 五字做事方式（本产品设计脊柱） |
