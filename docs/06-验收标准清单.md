# 06 · 验收标准清单（业务级 Acceptance Criteria）

全部业务级、可验证、可直接进 PRD 验收章节。`AC-HS-*` 健康分，`AC-DM-*` 决策管理。

---

## 一、项目健康分（AC-HS）

### A. 计算与数据正确性
- **AC-HS-01** 八维子分 S1–S8 各归一化到 0–100，越界自动钳制（<0 记 0，>100 记 100）。
- **AC-HS-02** 合成分 = Σ(权重ᵢ × Sᵢ)；权重按模式取值，总和恒为 100。
- **AC-HS-03** SPI = EV/PV、CPI = EV/AC；≥1.0 满分、< 0.85 归零、区间线性。
- **AC-HS-04** 某维度无数据时，该维度不计入合分，权重重新归一化，分数旁标注「数据不全」。
- **AC-HS-05** 度量变更后按周期（至少每日）或事件触发重算；历史分值留存可回溯。

### B. 一票否决
- **AC-HS-06** 命中任一否决项，状态灯强制红——即使合分 ≥ 80。
- **AC-HS-07** 否决项消除前不可回黄/绿；消除后按当前合分重新定级，不可红直接跳绿。
- **AC-HS-08** 分数旁显式列出命中否决项及证据，每条可下钻到根因记录。

### C. 状态与阈值
- **AC-HS-09** 边界明确：≥80 绿；[60,80) 黄；<60 红。
- **AC-HS-10** 取严：合分 ≥ 80 但任一子分 < 60 → 黄。
- **AC-HS-11** 优先级：**否决 > 子分<60 > 合分区间**。

### D. 趋势
- **AC-HS-12** 趋势按「当前 vs 上周期」Δ：超正阈值 ↗、超负阈值 ↘、之间 →；阈值可配。
- **AC-HS-13** 首周期无历史 → 不显示箭头，标注「无趋势数据」。

### E. 下钻与可解释
- **AC-HS-14** 四级下钻：合分 → 8 子分 → 底层度量 → 原始数据。
- **AC-HS-15** 任意红/黄节点须能定位到至少一条根因记录，不允许「红而无据」。
- **AC-HS-16** 子分旁显示对合分的贡献值与拖累值。
- **AC-HS-17** 任意分值可逐项拆解到度量与公式，无黑箱。

### F. 状态转换动作
- **AC-HS-18** 绿→黄：PM 24h 内提交偏差分析+纠偏，否则升级提醒发起人。
- **AC-HS-19** 黄→红：自动通知发起人，48h 内须提交恢复计划。
- **AC-HS-20** 红持续超阈值：上抛组合层仪表盘并触发治理/CCB 评审。
- **AC-HS-21** 所有状态转换记录时间、触发原因、相关人，形成审计日志。

### G. 配置与治理
- **AC-HS-22** 权重可由 PMO 按模板/模式配置，默认开箱即用。
- **AC-HS-23** 权重修改仅对未来生效，历史分值按当时权重锁定。

## 二、决策管理（AC-DM）

### A. 决策卡结构与创建护栏
- **AC-DM-01** 必填：标题、背景、≥2 选项、唯一决策人、截止时间、影响等级、关联对象——缺一不可创建。
- **AC-DM-02** 每选项必含：描述、对进度/成本/范围/质量量化影响、利弊、是否推荐。
- **AC-DM-03** 决策人字段强制唯一；多人或为空拒绝提交。
- **AC-DM-04** 标题须决策导向（含「A vs B」）；纯问题式标题给提示（非阻断）。

### B. 生命周期
- **AC-DM-05** 只允许定义流转：草拟→待决策→（超时→升级中）→已决→已执行→关闭，及任意→已撤销。
- **AC-DM-06** 已决须记录：所选选项 + 决策人 + 时间 + 理由。
- **AC-DM-07** 关闭前置：已生成至少一个落地动作（变更/任务/风险）并被确认；仅已决不可直接关闭。
- **AC-DM-08** 已撤销须记原因；退出决策债与健康分计算，审计记录保留。

### C. 自动升级
- **AC-DM-09** 截止达 50% 未决：自动提醒决策人。
- **AC-DM-10** 到截止时间未决：自动升级——通知决策人+其上级+PMO，转「升级中」，开始计决策债。
- **AC-DM-11** 逾期 N 天（可配）或阻塞里程碑在 Y 天内：强制升级到发起人/治理层。
- **AC-DM-12** 阻塞关键路径或里程碑的决策逾期：触发健康分一票否决 → 项目转红；落地后自动重算。
- **AC-DM-13** 所有升级系统自动执行，不依赖 PM 手动催办。

### D. 决策债
- **AC-DM-14** 决策债 = 逾期天数 × 影响等级权重；每日累加，落地即停息。
- **AC-DM-15** 债务仪表盘：总债值、最老决策、最大阻塞链。
- **AC-DM-16** 决策债是健康分 S5 主要输入；债值上升 → S5 下降。

### E. 留痕与防重开
- **AC-DM-17** 决策为永久记录：含提出人、全部选项（含被否决项及理由）、决策人、时间、所选。
- **AC-DM-18** 新建同类决策时提示历史决策，防止重复开题。
- **AC-DM-19** 留痕不可删除（可追加更正说明）。

### F. 联动
- **AC-DM-20** 按类型自动产生落地对象：变更→变更申请（CCB）；质量风险接受→风险登记；资源/任务→任务；go/no-go→状态门。
- **AC-DM-21** 落地对象可从决策卡跳转；对象状态回流决策（如变更被驳回→决策回待决策）。
- **AC-DM-22** 决策量化影响须同步更新健康分对应子分。

### G. RACI 与 SLA
- **AC-DM-23** 每决策标注 RACI：决策人(A,唯一)、提出人(R)、参与人(C)、知会人(I)。
- **AC-DM-24** 决策类型有默认决策人 + 默认 SLA，可被模板覆盖。
- **AC-DM-25** 决策人变更须经原决策人或发起人确认并留痕。

## 三、MVP 取舍（P0 必选）

- **健康分 P0**：AC-HS-01 / 02 / 03 / 06 / 09 / 14 / 18
- **决策 P0**：AC-DM-01 / 02 / 03 / 05 / 07 / 10 / 13 / 17

理由：先让「分能算、否决能转红、决策卡能建能升级能闭环」跑通。趋势、债务可视化、防重开为 P1 增量。
