# 06 · 验收标准清单（业务级 · 权威）

> **单一权威源声明**：本文件是验收标准的**权威目录**，已并入 docs/09 反检验全部补丁与本轮审查新增 AC，并与 docs/10 PRD、docs/08 路线对齐。PRD 各 FR 卡片引用此处编号；如本文与 PRD 表述差异，**以本文 AC 编号为准**，PRD 负责需求描述。

> 优先级：**P0**=MVP 必做 · **P1**=经营化 · **P2**=组织化 · **P3**=智能化。`[补]`=反检验/审查补丁，`[新]`=本轮审查新增。

## §0 横切 AC（适用所有模块）

- **AC-X01 [补]**：凡"提交方案/确认闭环/解除告警"类动作，**必须产出可追踪对象（行动项/落地动作，带责任人+截止）**，不接受纯自由文本；可追踪对象须有独立确认人，状态变更留痕可回溯。
- **AC-X01a [新]**：**交付物是制品(artifact)不受 X01 覆盖的盲区补丁**——交付物须挂验收 checklist（FR-WBS-01 已要求任务带验收标准），闭环时确认人逐条勾选 + 记录内容 hash + 确认人非自审；空文件/旧文档/失效外链不通过。P0
- **AC-X02 [新] · 数值证据化**：凡进入健康分/否决/决策债的**标量**（风险等级、决策影响等级、任务完成%、需求冻结度、受控变更率），必须挂接证据对象（基线快照/交付物/变更记录）或由独立角色（PMO/发起人）复核；等级变更走审计并触发历史回溯重算。**MVP 至少：风险等级、影响等级的变更需 PMO 或发起人确认。** P0
- **AC-SOLO-01 [新] · 单人/极小项目模式**：当项目有效成员 ≤1 或某对象 A=R 同人时，启用兜底——闭环改"责任人自报 + PMO/发起人 N 天内随机抽样审计"；决策允许"提出人=决策人"但强制抄送 PMO 并进高优审计队列；系统在 A=R 同人时自动上抛一级确认。P0
- **AC-ADMIN-01 [新] · Admin override 治理**：管理员越过固化约束须**双人确认**（Admin 发起 + 授权人）或 24h 内 PMO 复核；解除否决/跳 CCB 类 override 实时推 PMO；系统禁止 Admin 承担业务 R/A（不得作为某项目 PM/决策人）。P1

## §1 项目健康分（AC-HS）

> MVP 轻版仅 4 信号（见 AC-HS-LIGHT），完整 8 维为 P1。下表 AC-HS-01/02/03/14 属 P1 完整模型，**不计入 MVP P0**。

### 完整模型（P1）
- **AC-HS-01** 八维子分 S1–S8 各归一化 0–100，越界钳制。P1
- **AC-HS-02** 合成分 = Σ(权重ᵢ×Sᵢ)，权重按模式取值，总和 100。P1
- **AC-HS-03** CPI=EV/AC、SPI=EV/PV；**EAC、VAC、TCPI 一并计算**（见 §1EVM）；阈值**双层**：`<0.85 该维归零(黄层)`、`<0.75 一票否决(红层)`。P1
- **AC-HS-04** 某维度无数据→不计入合分、权重重归一化、标注"数据不全"。**P0**
- **AC-HS-04a [补·强化]** 有效维度数 **< 阈值**→显示「灰·评估中」**不得绿**。**阈值按阶段动态**：MVP=2 且须含"基线已建立"信号；P1 八维时=4。P0
- **AC-HS-05** 度量变更按周期/事件重算；历史分值留存可回溯。P1
- **AC-HS-06** 命中否决→强制红，即使合分≥80。P1
- **AC-HS-06a [补]** 恢复方案须为**可追踪行动项（非文本）**，进入"进行中/已关闭"前否决不解除。P1
- **AC-HS-06b [补·新]** 各否决项**按阶段标注是否启用**；缺数据/无基线的否决显示「未启用(缺数据/无基线)」，**禁静默放行绿**。P0
- **AC-HS-07** 否决消除后按当前分重新定级，不可红直接跳绿（须经黄）。P1
- **AC-HS-07b [新]** 颜色**转好须维持 ≥2 重算周期**；**红→绿禁止**，须经黄并闭环恢复行动项；阈值附近抖动不立即生效。P1
- **AC-HS-09** 边界：≥80 绿 / [60,80) 黄 / <60 红。P1
- **AC-HS-10** 取严：合分≥80 但任一子分<60→黄。P1
- **AC-HS-11** 优先级：否决 > 子分<60 > 合分区间。P1
- **AC-HS-12** 趋势 = 与**上一周期** Δ（≥3 周期滑动窗口，↗ 须 ≥2 连续周期正向且超阈值）。P1
- **AC-HS-14** 四级下钻：合分→8子分→度量→原始数据。P1
- **AC-HS-15** 红/黄节点须能定位根因记录，禁"红而无据"。P1
- **AC-HS-16** 子分旁显示贡献值与拖累值。P1
- **AC-HS-17** 任意分值可逐项拆解，无黑箱。P1
- **AC-HS-18** 绿→黄：PM 24h 内提交偏差分析+纠偏。P0
- **AC-HS-18a [补]** 纠偏/恢复方案须含**可追踪行动项**，纯文本不解除告警。P0
- **AC-HS-19** 黄→红：自动通知发起人，48h 内须提交恢复计划。P0
- **AC-HS-20** 红持续超阈值：上抛组合层 + 治理评审。P1
- **AC-HS-21** 所有状态转换记时间/原因/相关人，审计日志。P0
- **AC-HS-22** 权重 PMO 按模板配置，默认开箱即用。P1
- **AC-HS-23** 权重修改仅对未来生效，历史锁定；**项目级权重一旦设定不可中途改**（防偏向调分）。P1

### MVP 轻版（P0）
- **AC-HS-LIGHT-01 [新]** MVP 用 4 信号算粗粒度红黄绿：进度完成偏差（实际完成%−计划完成%，**非 SPI**）、逾期任务数、阻塞/逾期决策数、高危未关风险数。P0
- **AC-HS-LIGHT-02 [新]** MVP 否决：关键路径滑移、基线非受控突破——**按 AC-HS-06b 标注启用状态**（MVP 不算 CPM、若无基线则显示"未启用"，不得静默绿）。P0

### EVM 完工预测（P1）
- **AC-HS-EVM-01 [新]** 完整 EVM 须输出 **EAC = BAC/CPI（或 AC+ETC）、VAC = BAC−EAC、TCPI = (BAC−EV)/(BAC−AC)**，并设 EAC/VAC 预警阈值。P1

## §2 决策管理（AC-DM）

- **AC-DM-01** 必填：标题/背景/≥2选项/唯一决策人/截止/影响等级/关联对象。P0
- **AC-DM-01a [补·新]** 选项须**结构化互斥**（每个选项的进度/成本/范围取向不同），取向相同则拒。P0
- **AC-DM-01b [补·新]** 影响达阈值时**决策人≠提出人**，且提出人须在项目 RACI 内、有实际编辑贡献；截止 ≥now 且 ≤所阻塞里程碑。P0
- **AC-DM-02** 每选项含描述/量化影响/利弊/是否推荐。P0
- **AC-DM-03** 决策人字段唯一；多人/空拒绝。P0
- **AC-DM-04** 标题决策导向；纯问题式给提示。P1
- **AC-DM-05** 状态机：草拟→待决策→（超时→升级中）→已决→已执行→关闭 / 任意→已撤销。P0
- **AC-DM-05a [补·新]** **补回退弧**：`已执行→待决策`（落地被驳回/取消自动回流，重置计息时钟并标"回退"）、`已执行→已撤销`（走结构化撤销）；消除"已执行"死锁。P0
- **AC-DM-06** 已决记所选+决策人+时间+理由。P0
- **AC-DM-07** 关闭前置：已生成落地动作并被确认。P0
- **AC-DM-07a [补]** 落地动作须已执行/已关闭、类型与选项一致、回链决策；**落地动作与决策 N:1 强绑定**（一个动作只关闭一个决策，多决策共担须显式声明并按比例分摊债务）。P0
- **AC-DM-07b [补·新]** 确认人须为动作责任人/决策人，**禁自审**（单人项目走 AC-SOLO-01）。P0
- **AC-DM-07c [补·新]** 撤销理由结构化；"已实际执行"非合法撤销理由；**新决策与近 N 天已撤销决策做相似度匹配，超阈值须 PMO 解锁**；撤销率超阈值告警。P1
- **AC-DM-09** 截止 50% 提醒决策人。P0
- **AC-DM-10** 到期未决→自动升级（决策人+上级+PMO），转"升级中"，计决策债。P0
- **AC-DM-11** 逾期 **N=3** 天 或 阻塞里程碑在 **Y=5** 天内→强制升级发起人/治理。P0
- **AC-DM-12** 阻塞关键路径/里程碑的决策逾期→触发健康否决→红。P0
- **AC-DM-12a [补·新]** 阻塞关系声明或自动探测（任务标"等待决策"即建链；阻塞原因须结构化）。P0
- **AC-DM-12b [补·新]** 决策截止 ≤ 所阻塞里程碑（或 ≤里程碑−缓冲）。P0
- **AC-DM-13** 升级全自动，不依赖人工催办。P0
- **AC-DM-13a [补·新]** 升级目标可解析；失败默认 PMO/发起人；**逾期/过半后改 due date 受限且审计，逾期状态粘滞——改期不重置计息时钟**。P0
- **AC-DM-13b [新]** **升级中设硬超时 T2**（默认 5 工作日），T2 后自动上抛组合层并允许治理代决（CCB/治理委员会代决关闭或改派）；决策人=发起人/PMO 时升级路径强制跳 CCB。P1
- **AC-DM-14** 决策债 = 逾期天数×影响等级权重；每日累加，落地停息。P1
- **AC-DM-15** 债务仪表盘：总债值/最老/最大阻塞链。P1
- **AC-DM-16** 决策债是 S5 主要输入。P1
- **AC-DM-17** 决策永久记录：含提出人/全部选项（含被否决项及理由）/决策人/时间/所选。**P0**（留痕）
- **AC-DM-18** 新建同类决策提示历史决策，防重复开题。**P1**（防重开）
- **AC-DM-19** 留痕不可删除（可追加更正）。**P0**
- **AC-DM-20** 按类型派生落地对象（变更/风险/任务/状态门）。P0
- **AC-DM-21** 落地对象可跳转；状态回流决策。P0
- **AC-DM-22** 决策量化影响同步更新健康分子分。P1
- **AC-DM-23** 每决策标 RACI。P0
- **AC-DM-24** 决策类型有默认决策人+SLA，可被模板覆盖。P0
- **AC-DM-25** 决策人变更经原决策人/发起人确认并留痕；**原决策人失联（账号停用 N 天）自动放行发起人代确认**。P1

## §3 立项/章程（AC-PRJ）

- **AC-PRJ-01** 章程字段完整方可提交；立项即出初步 WBS+相关方清单。P0
- **AC-PRJ-02 [新]** **状态门**：无基线不得进入"执行中"（见 AC-BASE-01）。P0
- **AC-PRJ-03 [新]** 项目设最大执行期/无活动 N 月→自动进"挂起评审"，由发起人决定结项/延期/撤销（防永不结项）。P1

## §4 WBS/范围（AC-WBS）

- **AC-WBS-01** 任务创建强制带 交付物+责任人+截止+验收标准，缺一拒绝；粗任务须展开子环节方可"规划完成"。P0
- **AC-WBS-02 [新] · 范围漂移自动检测**：基线建立后，WBS 节点增/删/交付物变更/工期超容差→系统**自动生成变更申请**（不可绕过）；"需求冻结度/受控变更率"按系统 diff 计算，非 PM 自填。P0
- **AC-WBS-03 [新]** 任务撤销/拆分计入"已逃离任务"，作为 S7 独立扣分项（防拆分稀释逾期率）。P1

---

## §5 任务闭环（AC-TASK）

- **AC-TASK-01** 区分"状态"与"闭环"：须交付物上传 + 责任人确认关闭；关闭前过强制检查项（版本/谁拍板/纪要/影响节点）。P0
- **AC-TASK-02 [补·新]** 确认人须为责任人，**禁自审**（与 AC-DM-07b 一致；单人走 AC-SOLO-01）；交付物过 AC-X01a 质量门。P0
- **AC-TASK-03** 逾期/阻塞/无更新超 N 天自动推送。P0

---

## §6 基线/变更（AC-BASE）

- **AC-BASE-01 [新] · 强制基线**：项目进"执行中"前**必须建立基线**（AC-PRJ-02 状态门）；基线缺失→范围/进度/成本类否决显示"未启用(无基线)"且项目不得绿（纳入 AC-HS-04a 灰判定）。P0
- **AC-BASE-02 [新] · 重建不洗白**：重建基线后 CPI/SPI **历史方差不归零**，以"自原始基线起"累计作为否决输入；重建需发起人审批，健康分旁显示"重定基线 N 次"治理信号。P1
- **AC-BASE-03** 触及范围/进度/成本须走变更申请；非受控突破触发健康否决。P0
- **AC-BASE-04** MVP 变更(轻)：发起人确认（不走完整 CCB）。P0；完整 CCB 见 P1。

## §7 风险/问题（AC-RISK）

- **AC-RISK-01** 每条风险须有应对措施+责任人+关闭时间，否则永驻"未处理"并报警。P0
- **AC-RISK-02 [新] · 四策略枚举**：风险对象必填"应对策略"字段，枚举 **{规避 Avoid, 转移 Transfer, 减轻 Mitigate, 接受 Accept}**，按策略联动（转移→需第三方/合同；减轻→记残留暴露）。P0
- **AC-RISK-03 [新] · 风险闭环独立确认**：**高危风险关闭须发起人/PMO 确认**（与任务/决策对称，禁 PM 自开自关）；"风险→问题"重分类保留原风险记录并双计 S4，直到问题闭环。P0
- **AC-RISK-04** 客户"可能加需求"当场登记为变更候选项。P0

## §8 复盘/经验（AC-RET）

- **AC-RET-01** 收尾强制结构化复盘：逐项过 目标/范围/进度/成本/质量/满意度。P0
- **AC-RET-02 [新] · 资产结构化**：复盘须产出 ≥1 条**结构化可复用资产**（模板须可被下项目一键导入 / 规则须可挂成预警项 / 清单须可 attach 到 WBS 节点）；**PMO 抽审入库，拒绝即不予结项**；空话/万能废话不通过。P0
- **AC-RET-03 [新]** MVP 资产落到**单项目资产对象**（跨项目复用/推荐属 P1 FR-KB-01）。P0

## §9 自动化（AC-AUTO）

- **AC-AUTO-01** MVP 硬编码核心规则：决策到期升级、任务逾期提醒、风险无应对报警、健康阈值触发动作；不做自定义引擎。P0

## §10 里程碑（AC-MS）

- **AC-MS-01 [新]** 里程碑为一等对象：go/no-go、决策阻塞、否决均挂它；里程碑须有日期、责任人、验收标准。P0
- **AC-MS-02 [新]** 里程碑滑移计入健康分（S1/S8）；阻塞里程碑的决策/风险自动关联。P0
