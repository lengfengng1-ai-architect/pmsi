# 项目管理系统 · 业务设计文档

> 一句话定位：**不是「带看板的任务清单」，而是一套让战略落地到交付、可度量、可复盘的项目经营系统。**

## 设计来源

本设计融合两条主线：

1. **PMBOK 最佳实践**（十大知识领域 + 五大过程组 + 价值导向）——提供专业脊梁。
2. **微信文章《果然顶级项目经理，做事方式和普通人不一样！》** 的「**拆、控、推、追、回**」五字框架——提供产品灵魂（顶级 PM 的做事方式）。

结论：项目管理系统真正的价值，是把顶级 PM 的「拆控推追回」用 PMP 专业方法固化成**不依赖个人能力的组织能力**。

## 双骨架设计

- **明线（产品哲学 / 用户感知）**：拆、控、推、追、回——好记、好推。
- **暗线（专业脊梁 / 内在严谨）**：PMP 十大知识领域——保证不是花架子。

## 护城河（市场空白）

押在四个市场没解决对的能力上：**无痛 EVM、决策一等公民、数据驱动复盘、AI 副驾**，让普通团队也能按顶级 PM 的方式做事。
